DATABASE TABLES CREATED
=======================

1. user_sessions                [Track user sessions]
   - Columns: id, user_id, session_id, device_info, browser, os, 
             ip_address, started_at, ended_at, duration_seconds, 
             page_views, events_count, created_at, updated_at
   - Indexes: user_id, session_id, started_at, (user_id + started_at)

2. user_events                  [Individual user interactions]
   - Columns: id, user_id, session_id, event_type, event_name, 
             page_url, referrer_url, event_data, duration_ms, 
             timestamp, created_at
   - Indexes: user_id, session_id, event_type, event_name, 
             (user_id + timestamp), timestamp

3. heatmap_data                 [Click/interaction coordinates]
   - Columns: id, user_id, session_id, page_url, interaction_type, 
             x_coordinate, y_coordinate, element_id, element_class, 
             element_text, viewport_width, viewport_height, 
             timestamp, created_at
   - Indexes: user_id, session_id, page_url, interaction_type, 
             (page_url + interaction_type)

4. page_analytics               [Daily page metrics]
   - Columns: id, page_url, page_name, date, unique_visitors, 
             page_views, avg_time_on_page_seconds, bounce_rate, 
             scroll_depth_avg, ctr, conversion_rate, created_at, updated_at
   - Indexes: (page_url + date), date

5. session_recordings           [Recording metadata]
   - Columns: id, user_id, session_id, recording_url, storage_key, 
             duration_seconds, event_count, file_size_bytes, status, 
             started_at, ended_at, created_at
   - Indexes: user_id, session_id, status

6. heatmap_aggregates           [Pre-computed heatmaps]
   - Columns: id, page_url, date, interaction_type, heatmap_json, 
             sample_count, grid_size, created_at, updated_at
   - Indexes: (page_url + date + interaction_type), 
             (page_url + interaction_type)

7. user_analytics_summary       [Daily user summaries]
   - Columns: id, user_id, date, sessions_count, page_views, 
             events_count, total_time_seconds, unique_pages_visited, 
             conversions, conversion_value, goals_completed, 
             created_at, updated_at
   - Indexes: (user_id + date), date

8. analytics_custom_events      [Business-specific events]
   - Columns: id, user_id, event_category, event_label, event_value, 
             event_metadata, page_url, session_id, timestamp, created_at
   - Indexes: user_id, event_category, 
             (event_category + timestamp), timestamp


API ENDPOINTS CREATED
====================

Session Management:
  POST   /api/analytics/session/start              - Initialize session
  POST   /api/analytics/session/end                - End session

Event Tracking:
  POST   /api/analytics/event                      - Track any event
  POST   /api/analytics/heatmap                    - Track interaction
  POST   /api/analytics/custom-event               - Track custom event

Analytics Retrieval:
  GET    /api/analytics/page/:pageUrl              - Get page analytics
  GET    /api/analytics/session/:sessionId/events  - Get session events
  GET    /api/analytics/heatmap/:pageUrl           - Get heatmap data
  GET    /api/analytics/heatmap/aggregate/:pageUrl - Get aggregated heatmap

Reporting:
  POST   /api/analytics/heatmap/aggregate          - Generate heatmap
  GET    /api/analytics/trending                   - Get trending pages
  GET    /api/analytics/custom-events              - Get custom events


REACT HOOKS PROVIDED
====================

Main Hook:
  useAnalytics()                                   - Access all tracking functions

Page Tracking:
  useTrackPageView(pageName?)                      - Track page view

Element Tracking:
  useTrackClick(elementName, onTrack?)             - Track element clicks

Form Tracking:
  useTrackFormSubmission(formName)                 - Track form submissions

Engagement Tracking:
  useTrackTimeSpent(eventName?)                    - Measure time on component
  useTrackScrollDepth()                            - Track scroll depth (25%, 50%, 75%, 100%)
  useTrackSessionDuration()                        - Measure session duration
  useTrackElementVisibility(ref, eventLabel)       - Track element visibility

TROUBLESHOOTING
===============

Problem: Events not being tracked
Solution: 
  1. Verify AnalyticsProvider wraps app
  2. Check browser console for errors
  3. Verify Network tab shows /api/analytics/* requests
  4. Check backend is running

Problem: API 404 errors
Solution:
  1. Verify analytics routes registered in index.ts
  2. Check route path matches exactly
  3. Verify backend restarted
  4. Check API base URL in AnalyticsProvider

Problem: Database migration failed
Solution:
  1. Verify migration file exists
  2. Check database connection works
  3. Run: npm run migrate:check
  4. Try: npm run migrate:down then npm run migrate

Problem: Heatmap data empty
Solution:
  1. Generate aggregate: POST /api/analytics/heatmap/aggregate
  2. Verify page_url matches tracking
  3. Check database: SELECT COUNT(*) FROM heatmap_data
  4. Check date range in query
