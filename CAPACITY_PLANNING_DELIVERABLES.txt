DATABASE TABLES (6 NEW TABLES)
================================================================================

1. resource_metrics
   Purpose: Stores raw metric readings
   Retention: 90 days (auto-cleanup)
   Rows/minute: ~12 (typical system)
   Indexes: 2 (for performance)
   ├─ Timestamp index
   └─ (resource_type, metric_name) composite

2. capacity_trends
   Purpose: Stores aggregated metrics
   Periods: hourly, daily, weekly, monthly
   Contains: avg, min, max, p95, p99 values
   Calculation: Direction, rate, volatility
   Indexes: 1 (for efficient queries)

3. capacity_forecasts
   Purpose: Stores predicted future values
   Methods: Linear regression, exponential smoothing
   Includes: Confidence intervals, model metrics
   Accuracy: R² and MAPE calculations
   Indexes: 1 (for lookups)

4. capacity_thresholds
   Purpose: Alert threshold configuration
   Levels: warning, critical
   Features: Forecast-based alerting
   Indexes: 0 (small, frequently updated)

5. capacity_alerts
   Purpose: Historical alert records
   Levels: warning, critical
   Types: current_value, forecast_based
   Resolution: Tracks alert resolution
   Indexes: 1 (for unresolved alerts)

6. capacity_recommendations
   Purpose: Actionable recommendations
   Urgency: low, medium, high
   Effort: easy, moderate, difficult
   Tracking: Implementation status
   Indexes: 1 (for urgency filtering)

TOTAL INDEXES: 6
All indexes optimized for primary query patterns
